# Entretien

Ce qui se lance tout seul, les tâches système du Terminal, et désinstaller une app avec ses restes.

**[Télécharger la dernière version](https://github.com/gambidrissi-dev/Entretien-Share/releases/latest/download/Entretien.zip)** · macOS 14.0 ou plus récent

Ce dépôt ne contient pas de code : il distribue Entretien. L'app se met à jour toute seule
par [Sparkle](https://sparkle-project.org) depuis [`appcast.xml`](appcast.xml), et chaque archive est signée (EdDSA).

Toutes les apps, et **Vitrine** pour les installer d'un clic : https://apps-gambi.vercel.app/
